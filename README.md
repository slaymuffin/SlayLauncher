# ⚡ SlayLauncher

Современный лаунчер Minecraft с поддержкой Forge, Fabric, мод-браузера, автоустановки Java и Discord Rich Presence.

## ✨ Возможности

- 🎮 Установка Vanilla / Forge / Fabric в один клик
- 🧩 Мод-браузер (Modrinth + CurseForge) с иконками
- ☕ Автоустановка Java (Adoptium)
- 💾 Бэкапы миров
- 🏆 Достижения
- 🎯 Discord Rich Presence
- 🎨 6 тем (Vaporwave, Midnight, Forest, Halloween, Новый год, Light)
- 🔄 Проверка обновлений
- 📋 Просмотр логов

## 🚀 Скачать

Готовый `SlayLauncher.exe` — в разделе [Releases](../../releases/latest).
